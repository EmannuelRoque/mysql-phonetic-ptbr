# Problema

Bases cadastrais brasileiras sofrem com ruido textual recorrente:

- acentos e cedilha;
- apostrofos e pontuacao;
- particulas variaveis como `de`, `do`, `dos`, `das` e `d'`;
- espacos duplicados;
- nomes equivalentes escritos de formas diferentes.

O projeto busca reduzir esse ruido ainda no banco, com funcoes SQL puras e previsiveis.
