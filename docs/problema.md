# Problema

Bases cadastrais brasileiras sofrem com ruído textual recorrente:

- acentos e cedilha;
- apóstrofos e pontuação;
- partículas variáveis como `de`, `do`, `dos`, `das` e `d'`;
- espaços duplicados;
- nomes equivalentes escritos de formas diferentes.

O projeto busca reduzir esse ruído ainda no banco, com funções SQL puras e previsíveis.
